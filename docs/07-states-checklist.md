# 상태 화면 체크리스트

화면을 다 그렸으면 아래를 훑어보고, 이 화면에 해당하는 상태가 빠지지 않았는지 확인해요.
기획에 정의되지 않은 상태는 임의로 그리지 말고 **질문으로 남겨요.**

## 데이터 상태

| 상태 | 확인할 것 | 쓰는 컴포넌트 |
|---|---|---|
| 기본 (Default) | 데이터가 충분히 있을 때 | — |
| 로딩 | 처음 불러올 때, 더 불러올 때 | `♥︎loading` / `❤︎loading` |
| 빈 화면 | 결과 0건, 처음 사용 | `dataNotice` |
| 에러 | 네트워크 오류, 불러오기 실패 | `error Case` (재시도 버튼 포함 여부) |
| 데이터 적음 | 1~2건만 있을 때 레이아웃이 깨지지 않는지 | — |
| 데이터 많음 | 긴 목록, 페이지네이션·더보기 | Pagination (PC) |

## 상품·매장 상태

| 상태 | 확인할 것 | 쓰는 방법 |
|---|---|---|
| 품절 | 썸네일 표시 | 썸네일 `State=soldout` |
| 비활성 | 판매 중지·숨김 | 썸네일 `State=inactive`, 정보 `ActiveStatus=off` |
| 이미지 없음 | 상품·매장 이미지 누락 | 썸네일 `State=Empty_white/Empty_gray`, `Store_thumb_empty` |
| 멤버십 | 멤버십 매장·상품 표시 | `mbs_badge`, `badge_mbs` |

## 텍스트

| 확인할 것 | 기준 |
|---|---|
| 긴 텍스트 | 상품명·매장명이 길 때 말줄임 (`...`) 처리 |
| 두 줄 대응 | 드롭다운은 두 줄까지 위 정렬, 세 줄 이상 말줄임 |
| 숫자 | 큰 숫자(9,999+), 0, 가격 할인 표시 |
| 다국어 | 영어가 가장 길어요. 글로벌 화면이면 영어로 넘침 확인 |

## 입력·행동

| 상태 | 확인할 것 |
|---|---|
| 입력 | 기본 / 포커스 / 입력됨 / 에러 / 비활성 |
| 버튼 | 기본 / 눌림 / 비활성 / 로딩 |
| 선택 | 칩·탭·체크박스 선택·해제 |
| 확인 | 삭제·해지처럼 되돌릴 수 없는 행동 전 팝업·모달 |
| 결과 | 성공 토스트, 실패 안내 |

## 권한·조건 분기

| 확인할 것 |
|---|
| 로그인 전 / 후 |
| 도매 / 소매 |
| 멤버십 등급별 노출 차이 |
| 등급이 바뀌거나 권한이 없을 때 보이는 화면 |

## PC 해상도

| 확인할 것 |
|---|
| 1440에서 먼저 완성 |
| 1200·2000은 레이아웃이 달라지는 화면만 추가 (컴포넌트는 `Size` variant로 변경) |
