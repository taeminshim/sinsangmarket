## 0. 준비물

시작 전에 아래 세 가지가 되는지 확인해요. 하나라도 안 되면 그리는 도중에 멈춰요.

- [ ] **Claude에 Figma가 연결**되어 있다 (Claude 설정의 커넥터에서 Figma 연결)
- [ ] **신상마켓 라이브러리 4개**를 열 수 있다 ([README](../README.md#figma-바로가기)의 라이브러리 원본 링크)
- [ ] **이 저장소에 접근**할 수 있다 (비공개 저장소라 초대가 필요해요)

## 1. 프로젝트 참여

팀에서 만든 "신상마켓 화면 제작" Claude 프로젝트에 들어가요. 프로젝트 안에서 **새 대화**를 열면 규칙이 이미 들어 있어요.
프로젝트가 아직 없다면 1-b로 가요.

### 1-b. 프로젝트 만들기 (팀에서 한 명만)

1. Claude에서 프로젝트를 새로 만들어요. 이름 예: `신상마켓 화면 제작`
2. **프로젝트 지식**에 이 GitHub 저장소를 연결해요. 저장소를 고치면 프로젝트에도 반영돼요.
3. **프로젝트 지침**에 [CLAUDE.md](../CLAUDE.md) 내용을 통째로 붙여 넣어요.
4. 프로젝트를 팀원에게 공유해요.

> `CLAUDE.md`는 "어떤 문서를 읽어라"까지 안내하는 짧은 문서예요. 문서 본문(`docs/`)은 프로젝트 지식에 연결한 저장소에서 읽어요. 그래서 **지침과 저장소 연결, 둘 다** 필요해요.

## 2. 작업 파일 준비

요청하기 전에 Figma에서 아래를 준비해요.

| 준비물 | 방법 |
|---|---|
| **그릴 파일** | 내가 편집할 수 있는 작업 파일이에요. 새로 만들거나 기존 작업 파일을 써요. **라이브러리 원본 파일에는 그리지 않아요.** |
| **as-is 링크** (기존 화면 수정일 때) | 수정할 화면 **프레임**을 선택하고 우클릭 → `Copy link to selection`. 파일 전체 링크보다 정확해요. |
| **기획 링크** | Jira·Confluence 링크, 기획 이미지가 있는 프레임 링크, 또는 변경 내용을 글로 요약해도 돼요. |

## 3. 요청하기

[prompts](prompts.md)의 문장을 복사해서 `( )`만 바꿔 붙여요.

**기존 화면 수정 (가장 자주 써요)**

```
기획 변경에 맞춰 as-is 화면을 수정해줘.
- as-is: (Figma 화면 링크)
- 변경 내용: (기획서 링크 또는 변경 요약)
- 그릴 파일: (Figma 파일 링크)
그리기 전에 변경표 먼저 보여줘.
```

**새 화면**

```
신상마켓 iOS 기준으로 (화면 이름) 화면을 새로 그려줘.
- 기획: (기획서 링크 또는 요구사항)
- 그릴 파일: (Figma 파일 링크)
그리기 전에 화면 목록 먼저 보여줘.
```

## 4. 확인하고 받기

1. Claude가 **변경표**(수정) 또는 **화면 목록**(신규)을 먼저 보여줘요.
2. 기획과 다른 부분을 **그 자리에서** 고쳐 주세요. 그린 뒤에 고치는 것보다 훨씬 빨라요.
3. 확인하면 Claude가 Figma에 그려요.
4. 다 그린 뒤 Claude가 [08-audit](08-audit.md) 검수를 하고 **한 것과 남은 것**을 나눠서 보고해요.
5. "완료"라고만 하면 일부만 한 건 아닌지 물어보세요. 규칙상 일부만 했으면 완료라고 하지 않아요.

## 빠르게 쓰는 팁

그리는 시간은 대부분 Figma에서 컴포넌트를 찾고 연결하는 데 쓰여요. 아래를 지키면 눈에 띄게 줄어요.

| 팁 | 이유 |
|---|---|
| **프레임 단위 링크**를 준다 | 파일 전체 링크면 어떤 화면인지 먼저 찾아야 해요 |
| **변경표를 꼼꼼히 확인**한다 | 그린 뒤에 고치면 같은 화면을 두 번 그려요 |
| 기획 이미지는 **글로도 요약**해 준다 | 이미지만 있으면 읽다가 놓치는 부분이 생겨요 |
| 한 대화에서 **화면 1~2개**만 한다 | 대화가 길어지면 앞 내용을 놓치기 쉬워요 |
| **모바일과 PC를 나눠서** 요청한다 | 라이브러리와 스타일 키가 서로 달라요 |
| 정해지지 않은 건 **"질문으로 남겨줘"**라고 한다 | Claude가 정책을 지어내지 않고 질문으로 정리해요 |

## 자주 생기는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| Figma 파일을 못 읽는다 | 커넥터 미연결, 또는 파일 권한 없음 | Claude 설정에서 Figma 연결 확인, 파일 편집 권한 확인 |
| 컴포넌트를 못 찾는다 | 라이브러리가 파일에 추가되지 않음 | 그릴 파일의 Assets에서 라이브러리 4개가 켜져 있는지 확인 |
| 중간에 "오류"가 나고 멈춘다 | Figma 연결이 일시적으로 끊김 | "이어서 해줘"라고 하면 상태를 확인하고 이어가요 |
| 하드코딩 색·글자가 남는다 | 스타일 연결 누락 | "08-audit 기준으로 검수하고 고쳐줘" |
| 규칙과 다르게 그린다 | 프로젝트 지침이 오래됨 | 프로젝트 지침을 최신 [CLAUDE.md](../CLAUDE.md)로 교체 |
| 같은 실수를 반복한다 | 규칙에 없는 내용 | 해당 `docs/` 파일에 규칙을 추가하고 [CHANGELOG](../CHANGELOG.md)에 한 줄 남기기 |

## 팀이 같이 키우는 법

- 자주 막히는 부분을 발견하면 그때그때 `docs/`에 추가해 주세요. 다음부터 **모두에게** 반영돼요.
- 요청 문장이 잘 먹혔다면 [prompts](prompts.md)에 추가해 주세요.
- 기준을 고치면 [CHANGELOG](../CHANGELOG.md) 맨 위에 한 줄 남겨요. 형식은 `날짜 · 바꾼 사람 · 무엇을`이에요.
