# Claude에게 요청하는 법

"신상마켓 화면 제작" 프로젝트에서 새 대화를 열고, 아래 문장을 복사해 `( )`만 바꿔 쓰면 돼요.
프로젝트 지침에 규칙이 들어 있어서 따로 설명하지 않아도 돼요.

## A. 기획 변경에 따른 as-is 수정

```
기획 변경에 맞춰 as-is 화면을 수정해줘.
- as-is: (Figma 화면 링크)
- 변경 내용: (기획서 링크 또는 변경 요약)
- 그릴 파일: (Figma 파일 링크)
그리기 전에 변경표 먼저 보여줘.
```

## B. 새로운 화면 — 모바일

```
신상마켓 iOS 기준으로 (화면 이름) 화면을 새로 그려줘.
- 기획: (기획서 링크 또는 요구사항)
- 비슷한 기존 화면: (있으면 링크)
- 그릴 파일: (Figma 파일 링크)
그리기 전에 화면 목록 먼저 보여줘.
```

## B. 새로운 화면 — PC

```
신상마켓 PC 1440 기준으로 (화면 이름) 화면을 새로 그려줘.
1200·2000은 (필요 없음 / 레이아웃이 달라지는 부분만) 추가해줘.
- 기획: (링크)
- 그릴 파일: (Figma 파일 링크)
그리기 전에 화면 목록 먼저 보여줘.
```

## 상태 화면만 추가

```
이 화면(Figma 링크)에 상태 체크리스트 기준으로 빠진 상태를 찾아서 그려줘.
기획에 없는 상태는 그리지 말고 질문으로 정리해줘.
```

## 이미 그린 화면 검수

```
이 화면(Figma 링크)을 08-audit 기준으로 검수하고 걸린 걸 고쳐줘.
```

## 잘 되게 하는 팁

- **Figma 링크는 화면(프레임) 단위로** 주세요. 파일 전체 링크보다 정확해요.
- **그릴 파일은 편집 권한이 있는 작업 파일**이어야 해요. 라이브러리 원본 파일에는 그리지 않아요.
- 변경표나 화면 목록이 기획과 다르면 그 자리에서 고쳐 주세요. 그린 뒤에 고치는 것보다 빨라요.
- 결과가 기준과 다르면 "규칙과 다른 부분 찾아서 고쳐줘"라고 하면 돼요.
- 자주 틀리는 부분이 있으면 저장소 규칙에 추가해 주세요. 다음부터 모두에게 반영돼요.
